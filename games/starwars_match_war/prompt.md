# Features
- game is desktop and mobile friendly
- game has a start menu where the user chooses their team "JEDI" or "SITH"
- game loop involves:
  - choose your deck (pick characters you have unlocked), max of 7
  - start a map (9 by 9 grid of tiles that fall from the top of the grid)
  - match matches by swtiching positions of 2 tiles which make them disappear. match more tiles on the side of your team to win the "battle" in a randomly selected number of turns
  - at the end of a match the user gains emperial credits they can use to upgrade cards in their deck, add more turns to the next match, or do other things
